# Finishing a Development Branch (`finishing-a-development-branch`)

> 在实现完成且测试通过后，验证分支、识别基线分支，并在本地合并、创建 PR、保留分支或丢弃之间做出明确选择。

| 维度 | 说明 |
|---|---|
| 分类 | 计划与工程执行 |
| 阶段 | 开发完成与集成 |
| 主要使用者 | 开发、技术负责人 |
| 输出 | 合并结果、PR 或保留分支的决定及验证证据 |

## 1. 能力

先验证测试；识别工作区类型和基线分支；向用户展示集成选项；执行合并或创建 PR；合并后再次验证；清理已合并的分支。

## 2. 定位

**它负责：**

- 先验证测试
- 识别工作区类型和基线分支
- 向用户展示集成选项
- 执行合并或创建 PR
- 合并后再次验证
- 清理已合并的分支。

**它不负责：**

- 测试仍失败时宣称完成
- 尚未完成代码审查或验证时直接合并
- 替代产品验收
- 在没有用户确认时丢弃工作

## 3. 适用场景

- 功能实现完成，准备合并或发 PR
- 需要确认当前分支和目标基线
- 需要选择本地合并、PR、保留或丢弃
- 需要清理已合并的开发分支

## 4. 示例

**用户输入：**

```text
实现和测试都完成了。请确认基线分支，列出可选的集成方式，等我选择后再执行合并或创建 PR。
```

**Skill 的执行方式：**

1. 运行测试并确认通过
2. 识别当前环境和仓库形态
3. 确定目标基线分支
4. 展示合并、PR、保留、丢弃选项
5. 执行用户选择
6. 合并后再次验证并清理

**产出：**

合并提交、PR 链接、保留的分支，以及清理和验证记录。

## 5. 输入与输出

| 项目 | 说明 |
|---|---|
| 输入 | 实现完成状态、测试结果、当前分支、基线分支和用户集成偏好 |
| 输出 | 合并结果、PR 或保留分支的决定及验证证据 |
| 主要产物 | 合并提交、PR 或保留的分支 |
